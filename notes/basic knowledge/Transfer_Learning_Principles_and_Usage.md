

Transfer learning is:

> **Not learning from scratch, but utilizing knowledge that others have already learned.**

Take an example from daily life.

### Learning from Scratch

Suppose you have never learned English.

Now you are asked to learn French.

You need to learn:

```text
Alphabet
Vocabulary
Grammar
Pronunciation

Start everything over
```

Learning is very slow.

---

### Transfer Learning

If you already know English:

```text
cat
dog
apple
```

Then you learn French:

```text
chat
chien
pomme
```

Because you already have a lot of linguistic knowledge.

The learning speed will be much faster.

This is Transfer Learning.
